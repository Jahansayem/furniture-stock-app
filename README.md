# Furniture Stock App

Flutter furniture stock management app with Supabase backend — built for Adhunik Furniture, a sofa showroom in Moulvibazar, Bangladesh.

## What it does
- Track furniture stock, categories and quantities
- Supabase backend with row-level security
- Flutter app for shop staff to update stock on the go

## Run it
1. Copy `.env.example` to `.env` and fill in your Supabase URL and anon key. Never commit a real `.env`.
2. `flutter pub get`
3. `flutter run`

## Status
Active development. Used in a real showroom, not a demo.
