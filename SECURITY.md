# Security Policy

## Reporting a vulnerability
Please do not open a public issue for a security problem. Email the maintainer via the email on the GitHub profile, with steps to reproduce.

## What counts
- Exposed secrets, auth bypass, or data leaks
- Injection or access-control issues in the app or Supabase policies

## Out of scope
- Do not test against the live production site in a way that changes real listings or user data.
